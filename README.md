# Skill /lovable — Simone Guzzi Studio

Skill do Claude Code que abre e opera o **Open Lovable** do estúdio (cópia local do Lovable em `Desktop/open-lovable`, porta 3000).

## Instalar numa máquina

```bash
git clone https://github.com/admentreponto-ux/skill-lovable.git ~/.claude/skills/lovable
```

Depois disso, no Claude Code, digite `/lovable`.

As chaves de API ficam no `.env.local` do Open Lovable, nunca neste repositório.
